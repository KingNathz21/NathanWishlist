MY STATIC WISHLIST WEBSITE
==========================

HOW TO OPEN IT
1. Unzip the folder.
2. Double-click index.html.
3. It will open in your web browser.

HOW TO ADD OR EDIT WISHES
1. Open wishlist-data.js in Notepad, VS Code or another text editor.
2. Copy one complete item block inside the wishlistItems list.
3. Paste it beneath another item.
4. Change the name, category, price, priority, image, link and description.
5. Save the file and refresh index.html in your browser.

IMPORTANT
- Separate each item block with a comma.
- Prices should be numbers only, such as 79.99.
- purchased should be true or false, without quotation marks.
- priority should be "High", "Medium" or "Low".
- Dates should be written YYYY-MM-DD.

IMAGES
You can use:
- A direct online image URL.
- A local image saved in an images folder.

For a local image:
1. Create a folder called images beside index.html.
2. Put your image inside it.
3. Use image: "images/your-photo.jpg"

PUBLISHING FOR FREE
This website can be uploaded to GitHub Pages, Netlify or Cloudflare Pages.
